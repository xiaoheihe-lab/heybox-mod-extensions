# X4: Foundations 原生扩展适配器

Steam App ID：392160。通过 Steam 游戏发现定位 X4.exe，不绑定开发者的本机路径。

## 支持范围

- 定位 content.xml，原样部署清单所在目录中的 XML、Lua、CAT/DAT、模型、贴图等资源，包括无扩展名文件。
- 支持普通目录、深层包装和外层 extensions 目录；保留作者目录名。清单位于压缩包根目录时，使用合法的扩展 ID 作为目录名。
- 多个并列扩展作为同一个小黑盒 Mod 一起部署。不猜测并列组件是否互斥。
- 复制目标相对于 {gamePath}/extensions，例如 noelle_mod/content.xml，不重复追加 extensions。
- x4Extensions 属性记录扩展 ID 和目录。适配器只返回复制指令和属性，不删除文件、不执行外部工具。

## 管理边界

小黑盒管理部署文件，游戏内启用状态由 X4 管理。不读写用户文档目录中的启用状态 content.xml，不改写作者清单的依赖、版本或启用字段。

**已部署不等于游戏内已启用。** 玩家以前禁用过相同 ID 的扩展，重新部署后可能仍需进入游戏启用。

禁用、卸载、升级及已托管文件冲突交由客户端现有部署流程处理，不接管手动文件。现有同目录的清单和本次覆盖的每个文件必须有客户端托管记录。托管查询不可用且有冲突时保守拒绝，不根据目录名猜测所有权。

其他目录存在同 ID 扩展时，即使托管也拒绝，避免目录变更后重复部署。现有清单解析失败时也拒绝，以免漏检 ID 冲突。不同 ID 的 Nexus/Workshop 副本不保证能自动识别为重复 Mod。

拒绝危险路径、Windows 非法名称、文件/目录同名、大小写碰撞、官方 ego_dlc_ ID/目录以及目标路径中的符号链接或目录联接。不自动重命名资源。

## 首版不支持

- FOMOD、位于 options/optional 的选择包、嵌套清单，需先整理为选定组件的普通包。
- 自动安装依赖、扩展 ID 转小黑盒 modId、加载排序、Workshop 同步。
- 启动项、启动脚本、配置界面、ReShade、外部工具及游戏本体替换。

作者依赖声明原样保留，由游戏检查，不设统一加载器前置。

## 本地验证

在本目录依次执行：

```powershell
pnpm test
pnpm test:real --archive "D:/Downloads/your-mod.zip"
pnpm lint
pnpm build
```

test 使用 Node 测试框架和客户端 XML API 替身。test:real 使用 Windows PowerShell/.NET 解压并解析 XML，将等价对象交给正式安装器，对全部样本文件比较大小和 SHA-256，测试托管升级和模拟撤回。

真实包回放只写系统临时目录，结束后清理，不写真实游戏目录。XML API、游戏发现和托管记录均为替身；模拟撤回不代表真实客户端禁用/卸载已通过。

构建通过不代表真实 SDK 类型检查通过。需要在真实 heybox-mod-api 和 TypeScript 依赖齐全的环境执行 lint，不能用替代类型包冒充通过。

## 客户端和游戏验收

- [ ] 小黑盒实际安装，确认游戏 extensions/<作者目录>/ 下文件完整。
- [ ] X4 扩展界面确认名称、ID 和启用状态，进游戏验证效果。
- [ ] 实测禁用、重新启用、升级、卸载及客户端托管查询兼容性。
- [ ] 安装后加入手动文件，禁用/卸载时确认其与邻近扩展、DLC 均保留。
- [ ] 实测手动同目录、同 ID 扩展的冲突保护。

上述联调通过前不能宣称达到公开发布验收标准。
