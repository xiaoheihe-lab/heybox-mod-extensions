# X4: Foundations 扩展适配器

适用于 Steam 版 X4: Foundations（App ID：`392160`），部署目录为 `{gamePath}/extensions`。

## 功能范围

- 支持以 `content.xml` 为清单的 X4 原生扩展。
- 支持普通目录、外层 `extensions` 包装、深层包装和根目录清单。
- 支持单个安装包中的多个并列扩展，作为一个小黑盒 Mod 整体管理。
- 保留作者目录名、资源层级和文件内容；根目录清单使用扩展 ID 作为目标目录名。
- 支持 XML、Lua、CAT/DAT、模型、贴图、音效及无扩展名资源。
- 检查重复 ID、目标目录冲突、不安全路径及未托管文件覆盖，阻止以 `ego_dlc_` 开头的 ID 或目录作为安装目标。
- 保留作者依赖声明和游戏内启用配置，不接管手动安装的扩展。

更新、禁用和卸载由客户端部署机制处理，适配器不递归删除扩展目录。已托管文件允许更新，但不合并用户对托管文件的手动修改。游戏内启用状态与客户端部署状态独立。

## 功能限制

- 不支持 FOMOD、明确位于 `options/optional` 下的选项包或嵌套扩展清单；不判断并列组件是否互斥。
- 不自动下载依赖，不提供排序、配置编辑、Workshop 同步或重复副本识别。
- 不支持游戏本体替换、ReShade、外部工具及启动项管理。
- 不自动迁移目录改名的旧版本；其他目录存在相同 ID 时拒绝安装。
- 未托管目标冲突、现有清单解析失败，或托管查询失败且存在归属冲突时，拒绝安装。
- 部署校验不包含游戏版本、资源冲突、存档及运行效果兼容性检查。
